Coda Rust

Crate map

Every crate in crates/ is listed here, with the file where it starts and the chapter that covers its behavior. The module docs at the top of each entry file are the maintained description. When this table and a crate disagree, the crate is right and this table needs fixing. boundaries keeps Duet and the physician client from importing each other’s clinical crates. The Shared table below is the list of crates both products may use. One crate sits a level deeper: coda-sandbox, the agent sandbox tool, lives in crates/workspace-tools/sandbox/ and is listed under Tooling and guards.

Chrome extension

extension/ holds Coda’s Chrome extension, which reads the practice’s EHR under the physician’s own sign-in, and its local sandbox bridge and tests. Its popup is the extension-popup crate; the rest is not a Cargo crate. Its README covers loading it and running a sandbox read.
